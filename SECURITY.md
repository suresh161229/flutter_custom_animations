# Security Policy

## Supported Versions

Please refer to the [SUPPORTED_VERSIONS.md](SUPPORTED_VERSIONS.md) for a list of versions that are currently receiving security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within `flutter_custom_animations`, please DO NOT report it by creating a public GitHub issue.

Instead, please send an email to the maintainers or report it privately through GitHub's security advisory feature.

We will acknowledge receipt of your vulnerability report, and strive to send you regular updates about our progress. If a fix is necessary, we will provide a timeline for a patch release.
