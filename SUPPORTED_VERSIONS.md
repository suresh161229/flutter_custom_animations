# Supported Versions

We strive to keep `flutter_custom_animations` compatible with the latest versions of Flutter and Dart. 

| Version | Supported          | Flutter Version | Dart SDK       |
| ------- | ------------------ | --------------- | -------------- |
| ^1.0.0  | :white_check_mark: | >= 3.29.0       | >=3.7.2 <4.0.0 |

If you are using an older version of Flutter, we highly recommend upgrading to the latest stable release to benefit from performance improvements and new features in both Flutter and this package.
